System Architecture & Verification Guide

Welcome to the EV DashLab engineering guide. This section explains the hardware logic model, testbench structure, and verification concepts.

1. System Architecture

The speed controller logic operates on a 50 MHz system clock, taking an 8-bit digital throttle input (`0-255`), a 2-bit ride mode selector, and a 1-bit brake signal. It outputs an 8-bit target speed along with a PWM motor drive signal.

2. Safety-Critical Priority Logic

In standard vehicle safety logic, mechanical braking input override must execute with top priority over accelerator commands. When `brake_in == 1'b1`, the target speed drops to `0`, and `pwm_out` drops to `1'b0` within a single clock cycle.

3. How to Run External Simulations

  1. Copy the RTL design and testbench from the RTL Lab tab.
  2. Open EDA Playground and select Icarus Verilog 12.0 or Verilator as the simulator.
  3. Paste the RTL into `design.sv` and the testbench into `testbench.sv`.
  4. Check "Open EPWave after run" and click Run.
  5. Copy the terminal execution log and paste it back into EV DashLab to unlock verified hardware mode!
